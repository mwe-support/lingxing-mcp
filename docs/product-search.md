# Product Search

`lingxing_product_search` 用于按领星中文品名关键词筛选 ASIN，不要求输入完整品名。

## 示例

```json
{
  "query": "广告机/LED",
  "country_codes": ["US", "DE"],
  "store_names": ["MWE"],
  "limit": 20
}
```

`query` 可用斜杠、空格、逗号、顿号或分号分隔多个词。匹配前会统一全半角、大小写并移除空格。工具优先采用包含匹配；连续短语未直接包含时，允许品名中插入最多 4 个字符，例如 `桌面广告机` 可匹配 `桌面款广告机`。任一词命中即可进入候选，全部词命中的产品优先。匹配字段仅包括：

- `local_name`：领星本地中文品名，权重最高
- `item_name`：亚马逊商品标题，可匹配 LED 等英文缩写

## 筛选参数

- `country_codes`：国家/站点代码，例如 US、DE
- `sids`：领星店铺 SID
- `store_names`：店铺名关键词，采用包含匹配
- `limit`：返回数量，默认 20，最大 50

多个筛选条件同时提供时取交集。只查询启用中的店铺；未提供筛选条件时查询全部启用店铺，单次最多 200 个店铺。

## 数据和输出

工具内部使用 `POST /bd/productPerformance/openApi/asinList`，按 SKU 维度批量查询选定店铺最近 30 天的产品目录，并自动合并分页。查询时设置 `is_recently_enum=false`，日期仅满足接口要求，不作为用户的产品搜索条件。

返回值只包含排序后的候选，不返回完整商品目录。每个候选包括：

- 本地品名 `local_name`
- ASIN 列表 `asins`
- 关联店铺总数 `store_count`
- 命中的店铺 SID、店铺名和国家代码

每个候选最多展开 10 条店铺明细；当 `store_count` 大于 `stores` 数量时表示店铺明细已截断。内部相关度、命中词、标题、SKU 和 MSKU 仅用于筛选与排序，不进入 MCP 响应。

本工具不做语义翻译或向量检索。中文简称应能包含在领星本地品名中；英文缩写可匹配亚马逊标题。
